# Client report

Write in the client's language (default Dutch, Belgian conventions, `u` unless the project's voice guide says `je`). Plain words, no package names or version jargon beyond "Craft CMS 5.12". Short: one screen.

## What goes in

- Security fixes: that they were applied, how urgent they were, that no action is needed from the client.
- New features **editors will notice** (from Craft's author-facing changes), each with one sentence on how to use it.
- Anything the client must do or decide (for example: "approve the switch to …", "renew the license for …").
- What was tested.

## What stays out

- Developer-only changes, dependency names, npm/PHP versions (unless a hosting change affects them).
- Feature proposals that are not yet approved.

## Template (NL)

```markdown
Onderwerp: Onderhoud website <naam> – <maand jaar>

Hallo <naam>,

Deze maand hebben we de website bijgewerkt naar Craft CMS <versie>, samen met de plugins.

**Veiligheid**
<Eén of twee zinnen: welke soort lekken gedicht zijn en dat er niets van u verwacht wordt.>

**Nieuw voor redacteurs**
- <Functie>: <wat het doet en waar u het vindt.>

**Getest**
Alle paginatypes, de formulieren en de beheeromgeving werken zoals voorheen.

**Te beslissen** (alleen als van toepassing)
- <Vraag met een duidelijke aanbeveling.>

Vragen? Laat het gerust weten.

<handtekening>
```
