# Writing in Dutch (Belgium)

Source language for every site. Standard Dutch as written in Flanders: no dialect or tussentaal ("ge", "da's", "efkes"), and no Netherlands-only words. Apply [web-writing.md](web-writing.md) first, then this file. The voice guide wins where it differs (for example a deliberately informal brand).

## Belgian conventions

| Topic | Write | Not |
|---|---|---|
| Address | `u` by default for B2B and formal brands, `je` when the voice guide says so; never mixed on one site | switching u/je |
| Phone | gsm, +32 15 12 34 56 | mobiel, 06-… |
| Payment | betalen met Bancontact, kaart | pinnen |
| Numbers | 1.250,50; 15%; € 25 | 1,250.50 |
| Dates | 10 november 2026, dinsdag 10 november (lowercase days and months) | 10 November |
| Times | 9.30 uur, van 9 tot 17 uur; tables may use 09:00–17:00 | 9u30 in running text |
| Addresses | Bruul 1, 2800 Mechelen | |
| Headings | Sentence case: "Onze werkwijze in vier stappen" | Title Case: "Onze Werkwijze In Vier Stappen" |
| VAT | btw, excl. btw | BTW |
| Common terms | inschrijven, factuur, postcode, e-mailadres, aanvragen, contact opnemen | |

Spelling follows the Groene Boekje (woordenlijst.org); compound words are written together ("websitebeheer", "klantenservice"), with a hyphen for vowel clashes and abbreviations ("zee-egel", "btw-nummer").

## AI tells to remove

These patterns make text read as machine-written and generic. Remove them unless the voice guide explicitly wants one.

### Openings and closings

- "In de huidige (snel veranderende / digitale) wereld…", "In een wereld waarin…"
- "Of je nu … bent of …, wij…"
- "Stel je voor: …", "Welkom op onze website"
- "Kortom, …", "Al met al…", "Samengevat…" at the end of a section
- Rhetorical teaser headings: "Klaar om …?", "Op zoek naar …?", "Benieuwd naar …?"

### Inflated vocabulary

naadloos, cruciaal, essentieel, baanbrekend, toonaangevend, innovatief, revolutionair, uniek (unless proven), ongeëvenaard, transformeren, ontgrendelen, een wereld van mogelijkheden, op maat gemaakte oplossingen, totaaloplossing, one-stop-shop, ontzorgen, passie, beleving, "kwaliteit staat centraal", "de klant staat centraal", "met oog voor detail", "jarenlange ervaring" (without a number), "naar een hoger niveau tillen", "het verschil maken", synergie, holistisch, robuust, dynamisch, "duik in", "ontdek" as a reflex, "in het hart van", "een rijke geschiedenis", "verborgen parel", ultiem.

Replace with the specific fact, or delete.

### Sentence patterns

- "Niet alleen X, maar ook Y", "Het is niet X, het is Y": state Y.
- Three adjectives in a row ("snel, betrouwbaar en efficiënt"), and triads everywhere: use the one that's true and prove it.
- "Het is belangrijk om op te merken dat…", "Het spreekt voor zich dat…": cut.
- Stacked "zorgen voor" ("dit zorgt voor een vlotte werking"): name what happens.
- "Hierdoor…", "Dit zorgt ervoor dat…" chains: merge or cut.
- Colon headings ("Renovatie: een nieuwe start voor uw woning"): say it straight.
- Paragraphs that each end with a moral or a summary sentence.

### Anglicisms

| Anglicism | Dutch |
|---|---|
| "het verschil maken" (as a slogan) | say what changes |
| "aan het einde van de dag" | uiteindelijk |
| "op een dagelijkse basis" | dagelijks |
| "in termen van" | wat … betreft, qua |
| "dat gezegd zijnde" | toch, maar |
| "voel je vrij om ons te contacteren" | neem gerust contact op |
| "laten we …" (as an opener) | start with the point |
| "onze missie is …" (as filler) | what you do and for whom |
| "het maakt sense" | het is logisch |
| em dashes (—) for asides | comma, colon, parentheses or a new sentence |

### Weak style

- Nominalizations: "het uitvoeren van een analyse" → "we analyseren"; "het realiseren van" → "bouwen", "maken".
- Passive without a doer: "er wordt gezorgd voor" → who does it?
- "Wij"-centric: "Wij bieden een breed gamma aan diensten" → "U kunt bij ons terecht voor …" with the list.
- Hedging stacks: "eventueel", "mogelijk", "eigenlijk", "in principe" → decide or cut.
- Long noun stacks: "klantgerichte servicegarantieovereenkomst" → split it up.

### Formatting tells

- Emoji as bullets, bold scattered through every paragraph, every list exactly three items, every section the same length and shape.

## Self-review checklist

Run before showing copy, and again after edits:

```
- [ ] Main point in the first sentence of the page and of each section
- [ ] No phrase from "AI tells to remove" (search the text for each)
- [ ] Every claim has a fact or a [TE BEVESTIGEN] marker; no invented facts
- [ ] u/je consistent with the voice guide; Belgian conventions (gsm, dates, numbers)
- [ ] Headings: sentence case, informative, levels descend
- [ ] Sentences mostly ≤ 20 words; paragraphs ≤ 4 lines
- [ ] Link and button labels say what happens
- [ ] SEO title ≤ ~60 chars, meta description ~120–155 chars, slug short
- [ ] Alt text for every non-decorative image
- [ ] Read it aloud: would someone at this company say it to a customer?
```
